## What's new

- **Band-coloured plot traces** make it easier to compare beacon readings across bands.
- **Frequency-change markers** show the new frequency and, when known, the beacon callsign beneath it. Smoothing restarts at each frequency change, so readings from different frequencies stay separate.
- **Saved plots** retain frequency markers and callsigns. Older plot files still open.
- **OK1CDJ PathProfile** opens the station-to-beacon terrain path from the **Map** menu. It requires no subscription, API key or configuration.
- **Updated Operating Guide** illustrates the plot markers and both mapping options.

## Download and install

Download **VK3FS-Beacon-Strength-Plotter-Setup.exe** from **Assets** below. Close Beacon Strength Plotter if it is open, then run the installer on Windows 10 or 11.

## Beacon Strength Plotter v1.0.7

- Optional **Auto fetch BoM** fills in the current Australian Bureau of Meteorology synoptic chart URL and checks for a new chart whenever the Synoptic popup opens.
- The plotter heading and window title use the callsign saved in Setup.
- Refreshed USB and virtual COM port discovery, with optional radio auto-connect and retry after an unexpected disconnect.
- Clearer VKSpotter selection and import controls.
- The update checker recognises stable release tags with either a lowercase or uppercase V prefix.
- Updated Quick Start and Operating Guide PDFs are available from **Help**.

Download **VK3FS-Beacon-Strength-Plotter-Setup.exe** from **Assets** and run it on Windows 10 or 11.
